## HTML 的注释

### 什么是注释？

上学的时候，我们会在书本段落间记录内容的注解，方便下次看到此处理解。程序员在写代码的时候也会添加注释，方便下次看到此处的时候方便想起功能和含义。

```html
<html>
<!-- 这是一条注释 --> // [!code focus]
<!-- 网页的头部 --> // [!code focus]
  <head>
    <title>网页的标题</title>
  </head>

  <!-- 网页的主体 --> // [!code focus]
  <body>
    <h1>一级标题</h1>
    <p>段落</p>
  </body>

</html>
```

### 注释的作用

其一，为代码添加具有解释性、描述性的信息，主要用来帮助开发人员理解代码 。

其二，浏览器执行代码的时候会忽略所有的注释。

> 在 VS Code 中的注释快捷键是：`Ctrl` + `/` 。

## HTML 标签的构成

HTML 标签由开始标签、结束标签和标签内容组成。即：`<开始标签> 标签内容 </结束标签>`。

标签由 `<`、`>`、`/` 和 `英文单词` 或 `字母` 组成，并且将标签中的 `<>` 包括起来的英文单词或字母称为<b>标签名</b> 。

常见标签由两部分组成，我们称之为： 双标签 。前部分叫 开始标签，后部分叫 结束标签，两部分之间包裹内容。

少部分标签由一部分组成，我们称之为：单标签 。自称一体，无需包裹内容。

## HTML 标签的关系

父子关系（嵌套关系）：

```html
<head>
    <title>html的标题</title>
</head>
```

兄弟关系（并列关系）：

```html
<head></head>
<body></body>
```
