# GSAP 概述

一款极其强大的 JavaScript 动画库。专为专业人士打造。

GSAP 核心包含了为所有浏览器创建极其快速、响应式动画所需的**一切内容**。诸如**拖拽**、**滚动动画** 或 **变形** 等额外功能则包含在插件中。这使得核心部分相对精简，你可以仅在需要时添加功能。
